# **App Name**: PreRP

## Core Features:

- AI Academic Sage: An AI-powered tool that acts as a tutor to summarize notes, create flashcards, and answer queries from academic PDFs using advanced reasoning.
- Glassmorphic Command Center: A high-fidelity central dashboard featuring real-time attendance tracking and academic performance visualization through premium rounded glass cards.
- QR Pulse Attendance: An interactive interface for faculty to generate temporary QR codes and for students to check-in with micro-animations.
- Smart Document Transformer: A suite of file conversion utilities allowing students to merge, split, and transform study materials between PDF, Word, and PPT formats.
- Channel-Based Communication: Organized messaging workspace segmented by departments and subjects with real-time reactive feedback UI components.
- Gamified Quiz Arena: A competitive quiz environment featuring leaderboards, streaks, and achievement-based progression mechanics.
- Academic Vault: A streamlined repository for syllabus tracking, timetable management, and collaborative laboratory manual storage.

## Style Guidelines:

- Primary Color: Deep Electric Violet (#8B5CF6) to evoke a sense of high-tech academic precision.
- Background Color: Desaturated Dark Obsidian (#100E14), maintaining the same hue as the primary for a deep, immersive dark-mode experience.
- Accent Color: Azure Glow (#4876F5) used for calls to action, providing high contrast and vibrancy against the dark background.
- Headline Font: 'Space Grotesk' (sans-serif) for a techy, computerized feel; Body Font: 'Inter' (sans-serif) for objective readability in dense academic text.
- Premium Glassmorphism approach utilizing backdrop-filters, semi-transparent card overlays, and subtle rounded edges (24px) for a mobile-first Apple-inspired layout.
- Linear-style minimalist line icons with thin strokes and subtle gradient fills to match the futuristic startup aesthetic.
- Smooth micro-animations using Framer Motion for floating gradient orbs and gentle spring-based interactions on card hover and press.
